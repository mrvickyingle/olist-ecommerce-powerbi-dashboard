# Olist E-commerce Dashboard — Project Overview

## 1. Project Overview

The **Olist E-commerce Dashboard** is an interactive Business Intelligence project developed using **Microsoft Power BI**.

The purpose of this project is to analyze e-commerce business performance from different perspectives, including revenue, orders, customers, products, geographic regions, and delivery operations.

The dashboard converts raw e-commerce data into interactive reports and visualizations that make it easier to understand business performance and identify important trends.

---

## 2. Project Objectives

The main objectives of this project are:

* Analyze overall e-commerce sales performance.
* Monitor revenue and order trends.
* Analyze product and category performance.
* Understand customer distribution across regions.
* Compare business performance across Brazilian states.
* Analyze delivery performance.
* Identify delivered and late orders.
* Track important business KPIs.
* Provide interactive filtering and navigation.
* Enable detailed revenue analysis using a decomposition tree.

## 4. Dashboard Structure

The dashboard is divided into multiple analytical sections.

### 4.1 Executive Dashboard

The Executive Dashboard provides a high-level overview of the e-commerce business.

### Key KPIs

* Total Revenue
* Total Orders
* Total Customers
* Delivery Days
* Average Review

### Visualizations

* Monthly Revenue Trend
* Top Categories by Revenue
* Year-based filtering

This page is designed to provide a quick overview of overall business performance.

---

## 5. Product Analysis

The Product Analysis page focuses on product-level and category-level performance.

### Key Metrics

* Product Revenue
* Product Orders
* Products Sold
* Average Item Price
* Average Freight Value

### Analysis

The page helps analyze:

* Product sales performance
* Revenue generated by categories
* Product pricing
* Freight value
* Relationship between item price and freight value

Interactive visualizations allow users to explore product performance in greater detail.

---

## 6. Region Analysis

The Region Analysis page focuses on geographic performance.

The dashboard provides analysis based on customer locations and Brazilian states.

### Analysis Includes

* Revenue by state
* Product orders by state
* Product revenue by region
* Average delivery days
* Average freight value
* Geographic distribution

A map visualization is used to provide a geographical view of the business.

Users can also use the customer-state filter to analyze specific regions.

---

## 7. Delivery Analysis

The Delivery Analysis page focuses on order fulfillment and delivery performance.

### Key Metrics

* Delivery Days
* Delivered Revenue
* Delivered Orders
* Late Orders

### Analysis Includes

* Delivery status
* Delivered orders
* Late orders
* Delivery performance by state
* Customer-state filtering
* Year filtering

This section helps analyze the operational side of the e-commerce business.

---

## 8. Revenue Decomposition

The Revenue Decomposition page uses a **Decomposition Tree** to break down product revenue across different dimensions.

The visualization allows users to interactively explore revenue and understand how different categories or attributes contribute to the overall value.

This provides a more detailed way of investigating revenue patterns beyond standard charts.

## 11. Data Preparation

The project uses **Power Query** for data preparation and transformation.

The general data preparation workflow includes:

1. Importing the required data into Power BI.
2. Reviewing the available columns and data types.
3. Cleaning and transforming the data where required.
4. Preparing data for analysis.
5. Creating relationships between relevant tables.
6. Building the Power BI data model.
7. Creating DAX measures for important KPIs.
8. Creating interactive visualizations.

## 12. Data Modeling

## 16. How to Open the Project

1. Download the `Olist E-commerce Dashboard.pbix` file from the repository.
2. Install **Microsoft Power BI Desktop**.
3. Open the `.pbix` file in Power BI Desktop.
4. Allow the report to load its data sources if prompted.
5. Navigate through the dashboard pages using the available navigation controls.
6. Use the filters and visualizations to explore the analysis.
